# Public Evidence

`/evidence` is non-normative. Product and technical rules live exclusively in `/doc`.

The public repository intentionally does **not** contain raw Logcat captures, device dumps, screenshots with precise location context, or other unredacted runtime evidence. Those artifacts can contain exact coordinates, device identifiers, local paths, or other data that should not be published by default.

Only deliberately sanitized evidence belongs in this public repository. Raw acceptance evidence remains part of the private/local development workflow and can be summarized into `/doc` after acceptance.
